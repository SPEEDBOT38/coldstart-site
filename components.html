Workspace / component shelf

One home per component_

Every repeating piece of the workspace UI lives in exactly one place: a CSS block in css/workspace.css and, where markup repeats, a factory in the C layer of js/workspace.js. Views compose; they don't hand-roll. This page is the reference — if a view needs something not here, it gets added here first.
